# Contributing

1. Fork the repo and create a feature branch from `main`.
2. Install dependencies: `npm install`
3. Run the demo locally: `npm run dev`
4. Make your changes, then open a pull request against `main`.

## Code style

- No comments unless they explain something non-obvious.
- Keep SVGs small and optimized (run through SVGO or equivalent).
- One feature or fix per PR.
